Today's Concept

The Most Popular Agent Framework

LangChain is the dominant framework for building LLM applications. It provides composable abstractions for models, prompts, memory, tools, and chains.

LangGraph extends LangChain for stateful, multi-actor agent workflows using a graph-based execution model. Each node in the graph is an agent action; edges define conditional transitions based on state.

When to use each:
• LangChain — RAG pipelines, simple tool-using agents, quick prototypes
• LangGraph — complex multi-step agents, branching logic, human-in-the-loop, stateful workflows that need checkpointing and replay

LangGraph's key innovation: persistent state — the agent's full execution state is checkpointed, enabling pause/resume, time-travel debugging, and HITL interrupts.

Design Pattern
LangGraph State Machine
Model agent logic as a directed graph where nodes are actions and edges are conditional transitions based on the agent's current state.

Define State (TypedDict)
2
Create nodes (agent, tools, human_review)
3
Add edges (conditional: agent→tools or agent→END)
4
Set entry point
5
Compile graph
6
Invoke with initial state

Code Example — LangGraph State Machine
Python 
from langgraph.graph import StateGraph, END
from typing import TypedDict, Annotated

class AgentState(TypedDict):
    messages: list
    next_action: str

graph = StateGraph(AgentState)
graph.add_node('agent', agent_node)
graph.add_node('tools', tool_node)
graph.add_conditional_edges(
    'agent',
    lambda s: s['next_action'],  # 'tools' or 'end'
    {'tools': 'tools', 'end': END}
)
graph.add_edge('tools', 'agent')
graph.set_entry_point('agent')
app = graph.compile()
